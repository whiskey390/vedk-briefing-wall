TAF — Terminal Aerodrome Forecast · VEDO (nearest)

24-Hour Forecast · Nearest Reporting Station

VEDK itself does not issue a TAF. The nearest TAF station is VEDO (Deoghar, 17 NM NW). To wire up live TAF, extend the Python script to call the AWC TAF endpoint:

https://aviationweather.gov/api/data/taf?ids=VEDO&format=json
